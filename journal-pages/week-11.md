# Week 11

[← Back to Home](../index.md)

## Independent Study

This week I focused on completing the final version of my emotional awareness tool. Based on the previous prototype and the project direction from Week 10, I continued improving the system so that it could better help users understand their emotions through data.

The main focus this week was not to change the whole concept, but to make the existing system more complete and functional.

---

## Previous Version

The previous version already included emotion recording, emotion categories, intensity, triggers, reflection notes, and a weekly visual overview.

However, I wanted the system to become more detailed and useful for long-term emotional awareness.

![alt text](../assets/week-11/Screenshot%202026-05-29%20at%206.21.20 PM.png)

---

## Project Improvements

This week I made several important improvements:

- Added clear dates to emotional records
- Improved the emotion input system
- Allowed users to add or edit emotions for different days
- Added recent emotional trend analysis
- Added daily emotional references
- Strengthened the connection between data and reflection

These improvements helped the project become more complete and closer to the final version.

---

## Date-Based Emotional Tracking

One important improvement was adding clear dates to the emotional records.

The previous version focused mainly on weeks, days, and time periods. However, I wanted users to understand emotions within a more specific timeline.

The updated version now includes emotional records from late April to 29 May 2026.

This makes the system feel more realistic because users can connect emotions to actual dates. It also supports longer-term emotional tracking.

---

## Improved Emotion Input System

I also improved the Emotion Input section.

The system now allows users to select a specific date when adding or editing emotional records. This makes the tool more flexible because users are no longer limited to only the most recent records.

Users can now:

- Select a date
- Choose a primary emotion
- Choose a secondary emotion
- Select a time period
- Adjust emotion intensity
- Select a trigger
- Write a reflection note
- Add the record into the visualisation

This improvement makes the tool feel more like a real emotional diary system.

---

## Recent Emotional Trend Analysis

Another major improvement was the Recent Emotional Trend section.

This section helps users understand whether their recent emotional state is improving, declining, or remaining stable.

The system compares recent emotional records and gives a short summary of the emotional trend.

For example, it may show:

- Recent 7-day mood score
- Previous 7-day mood score
- Emotional rise or drop
- Possible reason
- Short suggestion

This feature is important because it moves the project beyond simple emotion recording. It helps users reflect on how their emotions change over time.

---

## Daily Emotional Reference

I also added a daily emotional reference section.

When users select a record, the system shows more detailed information about that emotional moment.

This includes:

- Primary emotion
- Secondary emotion
- Intensity
- Trigger
- Time
- Keywords
- Reflection note

This section helps users understand each emotional record in more detail.

Instead of only showing that an emotion happened, the system gives more context about why it may have happened.

---

## Final Prototype

After these improvements, the final version became much more complete.

The final system includes:

- Long-term emotional tracking
- Clear date-based records
- Emotion input system
- Primary and secondary emotions
- Emotion intensity
- Trigger categories
- Reflection notes
- Mood filter
- Time filter
- Selected record information
- Awareness insight
- Recent emotional trend analysis

## Reflection

This week helped me complete the final functional version of the project.

The biggest improvement was moving from simple emotional recording to emotional awareness. The system now does more than collect emotion data. It helps users observe dates, triggers, patterns, and recent emotional changes.

This also connects to the project direction from Week 10. The project is no longer trying to directly solve emotional problems. Instead, it helps users better understand their emotions through personal data.

I think this final version is much stronger because it gives users more ways to reflect on their emotional experiences. The date system, input system, daily references, and emotional trend analysis all support the goal of emotional awareness.

For the final showcase, I want to present this project as an interactive emotional awareness tool that helps users recognise emotional patterns and understand their emotional habits over time.
